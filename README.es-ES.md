# Guía de instalación:
## Esta guía es para un servidor FiveM nuevo
### ¡Importante! Si tienes un servidor TxAdmin, debes seleccionar Popular Template durante la configuración de TxAdmin y luego Default CFX.

- En un vServer o Rootserver, primero debes instalar un servidor FiveM limpio en él.
-- https://docs.fivem.net/docs/server-manual/setting-up-a-server-vanilla/
- Para un vServer o Rootserver, necesitas la membresía FiveM Element Club Argentum para usar OneSync.
- Para un servidor de juegos de Zap-hosting, solo necesitas la membresía FiveM Element Club Argentum cuando superes los 48 slots.
- Versión del servidor FiveM mínima: 6552

- Para obtener más ayuda, puedes apoyar el proyecto y acceder al sistema de tickets: https://shop.achimsommer.com/package/5708271 


1.
Añade las siguientes carpetas a tu carpeta resources:
- [core]
- [esxaddon]
- [esxjobs]
- [extras]
- [maps]
- [mskscripts]
- [ox]
- [phone]
- [templateserveraddon]

2.
Añade los siguientes archivos a tu carpeta server-data:
- inventory.cfg
- maps.cfg
- phone.cfg
- server.cfg

3.
Introduce la conexión de tu base de datos MySQL en el server.cfg:
- ver línea 16

4.
Introduce tu SteamID64(hex) en el server.cfg para convertirte en administrador:
- ver línea 68

5.
Introduce tu steam_webApiKey en el server.cfg:
- ver línea 74
- https://forum.achimsommer.com/home/lexicon/entry/13-fivem-server-steam-api-key-fivem-steam-wird-nicht-erkann/

6.
Importa el archivo server.sql de la carpeta [SQL] a tu base de datos mediante phpmyadmin:

7.
Consigue el paquete de Soporte o el paquete de Soporte con Addons si lo deseas, para apoyar el proyecto.
